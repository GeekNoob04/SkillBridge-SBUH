

# Freelance AI Assistant

A Streamlit-based web application that serves as a freelance platform AI chatbot, leveraging Google's Gemini Pro model for intelligent responses and supporting both text and voice input.

---

## 🧠 Project Overview

This project provides a user-friendly interface for interacting with an AI chatbot designed specifically for freelance platform queries. The application integrates Google's Gemini Pro model for generating responses and supports both text and voice input, making it accessible and versatile for users.

---

## 🚀 Features

- **AI-Powered Responses:** Leverages Google's Gemini Pro model for intelligent and context-aware responses.
- **Text Input:** Users can type their queries directly into the interface.
- **Voice Input:** Supports voice-activated input for hands-free interaction.
- **Chat History:** Maintains a history of interactions for easy reference.
- **User-Friendly Interface:** Built with Streamlit for a clean and intuitive user experience.

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit for building the web interface.
- **AI/ML:** Google Generative AI (Gemini Pro) for response generation.
- **Speech Recognition:** Google Speech Recognition for voice input.
- **Environment Management:** Dotenv for handling environment variables.

---

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/GeekNoob04/SkillBridge-SBUH/
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set up your environment variables by creating a `.env` file and adding your Google API key:
   ```bash
   GOOGLE_API_KEY="your-api-key-here"
   ```

---

## 💻 Usage

1. Run the application using Streamlit:
   ```bash
   streamlit run ai.py
   ```
2. Interact with the chatbot using either text or voice input.
